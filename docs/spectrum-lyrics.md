# 频谱和歌词界面改了什么

源码已经改过。你现在看到的多半还是 9 月 14 日的 `target/release/zradio`。要看到新界面，先重新编译再开。

## 先编译

在仓库根目录执行：

```sh
cd /home/xender/xender-working/ZRadio
cargo build --release
./target/release/zradio
```

不要用旧的 `zradio` 命令，除非你确认它指向这份刚编出来的二进制。

## 看哪里

终端从上到下大致是：顶栏、状态条、曲库+封面、**频谱**、当前曲目条、帮助。

| 位置 | 旧样子 | 新样子 |
|---|---|---|
| 频谱 | 中间一条窄灰块，外面有框，标题是 `spectrum` | 整行铺满宽度，没有外框和标题。柱从底往上长。底部深灰，峰值才亮黄 |
| 歌词 | 封面下面左边对齐的 6 行，当前行前面有 `▸`，标题是 `lyrics` | 封面变矮，歌词区变高。当前行居中、加粗、亮黄。上一行下一行浅灰，更远的更暗。没有 `lyrics` 标题 |
| 空歌词 | ` no lyrics ` | 居中一行灰字 `no lyrics` |

频谱只有在真正出声时才会动。暂停时柱很矮，看起来几乎没改。

歌词只有当前曲有内嵌歌词或同目录 `.lrc` 才会居中滚动。没有歌词文件时，右边只显示 `no lyrics`，和以前差别很小。

## 代码落点

- 频谱铺宽：`src/spectrum.rs` 里的 `bars_sized`
- 频谱上色、去掉外框：`src/ui.rs` 的 `draw_spectrum`
- 歌词窗口（当前行居中）：`src/meta.rs` 的 `lyric_window`
- 歌词绘制：`src/ui.rs` 的 `draw_lyrics`

## 还没验证的

真机听歌观感。编完播一首有 `.lrc` 的歌，看右边当前行是否居中发黄；频谱是否拉满整行。太淡或太抢再说。
